# Logos de equipos NFL

Coloca aquí los logos oficiales de cada franquicia en formato `.png` con fondo transparente. El nombre del archivo debe seguir el patrón `nombre-del-equipo.png`, todo en minúsculas y separando espacios por guiones, por ejemplo:

- `san-francisco-49ers.png`
- `philadelphia-eagles.png`

Estos nombres coinciden con el mapeo usado en la interfaz.
